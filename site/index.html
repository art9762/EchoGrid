Positioning

A hypothesis lab — not a crystal ball

EchoGrid generates synthetic simulation outputs to explore communication dynamics. Treat them as ideas to test, never as measured public opinion.

What it is

A synthetic society simulator

  • Builds synthetic agents with demographic, economic, psychological, social, and media-consumption profiles.
  • Simulates media framings of a public event and each agent's initial reaction.
  • Propagates social and media echo items through multi-round cascades inside bubbles.
  • Reports before/after metrics: amplification, trust, anger, distortion, polarization.
What it is not

Not a poll, not a prediction

  • Not a polling tool — it does not measure or predict actual public opinion.
  • Not scientifically calibrated — mock mode is plausible and deterministic, not survey evidence.
  • Not a persuasion optimizer — never for manipulation or political targeting.
  • Not for harm — no harassment, radicalization, or targeting of vulnerable groups.
Pipeline

How it works

One news event flows through six deterministic stages. Each stage feeds the next, ending in measurable before/after metrics.

  1. 01

    News event

    Enter or pick a public information event to test.

  2. 02

    Synthetic population

    Generate up to 1000 agents with rich profiles.

  3. 03

    Media framings

    Outlets frame the event across an ecosystem.

  4. 04

    Initial reactions

    Each agent reacts to the framings it sees.

  5. 05

    Echo cascade

    Echo items ripple through bubbles in rounds.

  6. 06

    Final metrics

    Compare before/after, then store and export.

Capabilities

Built for serious exploration

A full simulation stack — population, media, cascades, metrics, storage, and tunable run modes — running locally.

1000 synthetic agents
7 demo scenarios
3 run modes
5 echo metrics

Synthetic population profiles

Agents with demographic, economic, psychological, social, and media-consumption attributes.

Media ecosystem

Configurable outlets and presets that frame the same event in competing ways.

Multi-round echo cascades

Bounded multi-round propagation of echo items inside social bubbles.

Before / after metrics

Amplification, trust, anger, distortion, and polarization, compared end to end.

Storage & export

SQLite persistence with CSV, JSON, and full ZIP bundle exports of every run.

Three run modes

Mock (fully local), Hybrid (bounded LLM calls), and capped Full LLM sample.

Responsible use

Use it to understand, never to manipulate

EchoGrid produces synthetic outputs as hypothesis-generation artifacts. These boundaries are not optional.

Allowed

  • Research and hypothesis generation
  • Education and teaching media literacy
  • Communication-risk analysis
  • Media-dynamics exploration

Disallowed

  • Optimizing manipulative persuasion
  • Political targeting
  • Harassment or radicalization
  • Targeting vulnerable groups
Get started

Run it locally

Clone the repo, install requirements, and launch the Streamlit dashboard. Mock mode runs with zero API keys.

$ streamlit run app.py
