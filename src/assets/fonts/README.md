# Bundled report fonts

Noto Sans Regular and Bold are distributed unmodified under the **SIL Open Font
License 1.1**, included verbatim in [OFL.txt](OFL.txt). Copyright 2018 The Noto
Project Authors. These fonts cover Latin, Greek and Cyrillic, including Russian.
The PDF renderer embeds subsets; it never searches a user's system font folders.
Characters outside the font's coverage are shown as `[U+XXXX]` code points.

Source: [notofonts/noto-fonts](https://github.com/notofonts/noto-fonts), commit
`ffebf8c1ee449e544955a7e813c54f9b73848eac`, files under
`hinted/ttf/NotoSans/`; the license is the repository's `LICENSE` at that commit.
